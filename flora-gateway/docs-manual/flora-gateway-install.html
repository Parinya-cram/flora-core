1 ภาพรวมและการเลือกแพลตฟอร์ม

Flora Gateway รับข้อมูลจากเครื่องมือแพทย์ (RS-232 และ LAN) แปลงเป็นค่ากลางของ Flora แล้วให้ Flora Leaf ดึงไปแสดงผล คู่มือนี้ติดตั้งแบบ ใช้งานจริง โดยมีเงื่อนไขสำคัญ:

เงื่อนไข: พอร์ตจริงเท่านั้น ไม่มีพอร์ต serial เสมือน (/dev/ttyV*, TCP bridge 7430/7431), ไม่มีเครื่องจำลอง (simulator) และมีด่าน port-guard ตรวจ config ทุกครั้งก่อนเริ่มระบบ ถ้าพบพอร์ตเสมือนหรือพอร์ตที่ไม่มีอยู่จริง ระบบจะไม่ยอมเริ่ม

3 ติดตั้งบน Ubuntu (Docker Engine)

3.1 เตรียมเครื่อง

sudo apt update && sudo apt -y upgrade
sudo apt -y install git curl openssl python3 python3-serial
sudo usermod -aG dialout $USER                # สิทธิ์ใช้พอร์ต serial
sudo systemctl disable --now ModemManager       # กันโปรแกรมแย่งพอร์ต serial

ตรวจพอร์ต serial จริงของเครื่อง (type ไม่ใช่ 0 = มีฮาร์ดแวร์จริง):

for d in /sys/class/tty/ttyS*; do t=$(cat $d/type); [ "$t" != 0 ] && echo "$(basename $d) io=$(cat $d/port)"; done
ls -l /dev/serial/by-id/ 2>/dev/null          # USB-RS232 (ถ้ามี)

3.2 ติดตั้ง Docker Engine

sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] \
  https://download.docker.com/linux/ubuntu $(. /etc/os-release; echo $VERSION_CODENAME) stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt -y install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker containerd   # เริ่มเองตอน boot
sudo usermod -aG docker $USER                   # แล้ว logout / login ใหม่
echo '{"log-driver":"json-file","log-opts":{"max-size":"20m","max-file":"5"}}' | sudo tee /etc/docker/daemon.json
sudo systemctl restart docker
ไม่ใช้ Docker Desktop บน LinuxDocker Desktop map พอร์ต serial จริงเข้า container ไม่ได้ เปลี่ยน IP ต้นทางของเครื่องที่ต่อเข้ามา และต้องมีคน login ก่อนจึงจะเริ่ม ถ้าเคยติดตั้งไว้ให้รัน docker context use default และ systemctl --user disable --now docker-desktop

3.3 ดึงโค้ด

mkdir -p ~/flora && cd ~/flora
git clone http://172.22.1.103:8080/esm-solution/flora-esm flora-core
cd flora-core && git checkout gateway-g             # branch ที่มีชุดติดตั้งนี้
cd flora-gateway
ห้ามย้ายโฟลเดอร์หลังติดตั้งถ้าย้าย Docker จะสร้างโฟลเดอร์เปล่าแทนไฟล์ที่ mount ไว้ ทำให้ฐานข้อมูลเริ่มไม่ได้

3.4 ตั้งค่า .env

สร้างไฟล์ flora-gateway/.env (ตัวอย่างเต็มในหัวข้อ 9.1):

FLORA_GATEWAY_ID=gateway-hospital-01-a
HABER_URL=http://172.22.19.81:7204
GATEWAY_DATA_API_URL=http://172.22.1.233:7410/data-api
FLORA_GATEWAY_CONFIG_FILE=gateway.site.toml
FLORA_GATEWAY_SEED_FILE=instances.site.json
FLORA_GATEWAY_ADMIN_BIND=0.0.0.0
FLORA_SERIAL_PORT_1=/dev/ttyS0
FLORA_SERIAL_PORT_2=/dev/ttyS1
FLORA_GATEWAY_DB_PASSWORD=<ตั้งรหัสใหม่>
GATEWAY_ADMIN_PASSWORD=<ตั้งรหัสใหม่>

3.5 ตั้งค่าพอร์ตจริง (gateway.site.toml)

cp config/gateway.toml config/gateway.site.toml
echo '[]' > config/instances.site.json

แก้ config/gateway.site.toml ให้ serial pod ชี้ไปพอร์ตจริงเท่านั้น และลบ pod ของเครื่องจำลองออก:

[[serial.pods]]
id = "COM1"
path = "/dev/ttyS0"      # พอร์ตจริงที่ map ใน FLORA_SERIAL_PORT_1
baud = 9600              # ค่าสายจะถูกตั้งตาม Device type ให้เองเมื่อเพิ่ม device

[[serial.pods]]
id = "COM2"
path = "/dev/ttyS1"      # พอร์ตจริงที่ map ใน FLORA_SERIAL_PORT_2
  • ลบ pod ที่ใช้ /dev/ttyV* และ URL ของ simulator (ใน [feeder], [publisher]) ออก
  • USB-RS232: ใช้ชื่อถาวรจาก /dev/serial/by-id/… และเพิ่มบรรทัด devices ใน compose.production.yaml
python3 scripts/validate_config.py config/gateway.site.toml config/instances.site.json

3.6 Certificate สำหรับ HTTPS (edge)

service edge (HTTPS พอร์ต 443) ต้องมี cert ถ้าไม่มี Docker จะสร้างโฟลเดอร์เปล่าแทนไฟล์และ edge จะ restart วนซ้ำ ใช้ cert ขององค์กร หรือสร้างแบบ self-signed:

cd certs
openssl req -x509 -newkey rsa:2048 -nodes -days 730 -keyout server.key -out server.crt \
  -subj "/CN=flora-gateway" -addext "subjectAltName=IP:172.22.1.233,IP:127.0.0.1,DNS:localhost"
chmod 600 server.key && cd ..

3.7 Build และเริ่มระบบ

docker compose -p flora-gateway -f compose.production.yaml up -d --build
docker compose -p flora-gateway -f compose.production.yaml logs port-guard

ผลที่ถูกต้องของ port-guard:

port-guard: /dev/ttyS0 ok
port-guard: /dev/ttyS1 ok
port-guard: real serial ports only — ok
ต้องใส่ -f compose.production.yaml ทุกครั้งถ้ารัน docker compose up โดยไม่ระบุ จะใช้ compose.yaml (dev/demo) ซึ่งเปิดพอร์ตเสมือน

3.8 เริ่มเองเมื่อเปิดเครื่อง

  • Docker Engine เริ่มตอน boot และ container ทุกตัวตั้ง restart: unless-stopped ไว้แล้ว ไม่ต้อง login
  • service เสริมของผู้ใช้ (log การทำงาน flora-watch, relay ของ M540 flora-iacs-relay) ให้เปิด linger:
sudo loginctl enable-linger $USER
systemctl --user enable flora-watch flora-iacs-relay

ทดสอบ: รีบูตแล้วปล่อยไว้ที่หน้า login จากนั้นเปิด http://<gateway>:7400 จากเครื่องอื่น

4 ติดตั้งบน Windows 10 / 11

หลักการบน WindowsDocker Desktop ส่งพอร์ต COM ของ Windows เข้า container ไม่ได้ จึงรัน serial-controller บน Windows โดยตรง (เปิด COM1, COM2 จริง) ส่วนอื่นรันใน Docker Desktop สคริปต์ windows\start-gateway.ps1 จัดการทั้งหมดให้

4.1 ติดตั้งซอฟต์แวร์

โปรแกรมหมายเหตุ
Windows 10 21H2+ / Windows 1164-bit, เปิด virtualization ใน BIOS
WSL2PowerShell (Admin): wsl --install แล้วรีสตาร์ต
Docker Desktopเลือก WSL2 backend · Settings → General → Start Docker Desktop when you sign in · Resources → Memory 4 GB+
Git for Windowsใช้ดึงโค้ด
Rust (rustup) + Visual Studio Build Toolshttps://rustup.rs และเลือก "Desktop development with C++" (ใช้ build serial-controller.exe)

อนุญาตให้รันสคริปต์ PowerShell ของผู้ใช้ (ครั้งเดียว):

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

4.2 ดึงโค้ดและตั้งค่า .env

cd flora-core; git checkout gateway-g; cd flora-gateway

สร้าง .env (เหมือน Linux แต่ใช้ไฟล์ config ของ Windows และ data-api เป็น IP ของเครื่อง Windows):

FLORA_GATEWAY_ID=gateway-hospital-01-a
HABER_URL=http://172.22.19.81:7204

FLORA_GATEWAY_DB_PASSWORD=<ตั้งรหัสใหม่>
GATEWAY_ADMIN_PASSWORD=<ตั้งรหัสใหม่>
ปัญหาปลายบรรทัด (CRLF)Git บน Windows อาจแปลงปลายบรรทัดเป็น CRLF ไฟล์ .env และ .toml ใช้ได้ทั้งสองแบบ แต่ถ้าแก้ไฟล์ด้วย Notepad ให้บันทึกเป็น UTF-8

4.3 ตั้งค่าพอร์ต COM จริง (gateway.windows.toml)

  1. เปิด Device Manager → Ports (COM & LPT) ดูชื่อพอร์ต เช่น Communications Port (COM1), USB Serial Port (COM3)
  2. แก้ config\gateway.windows.toml ให้ path ของแต่ละ pod ตรงกับชื่อพอร์ต ("COM1", "COM3" …)
  3. ตรวจว่าเป็นพอร์ตจริง:
.\windows\check-com-ports.ps1
ok   COM1 : Communications Port (COM1) [ACPI\PNP0501\0]
ok   COM3 : USB Serial Port (COM3) [FTDIBUS\VID_0403+PID_6001+...]
check-com-ports: all serial pods use physical COM ports

ที่มาของพอร์ต: ACPI\ = บนเมนบอร์ด, USB\/FTDIBUS\ = USB adapter, PCI\ = การ์ด ถ้าเป็นพอร์ตเสมือน (com0com, Eltima, VSPE หรือ ROOT\) จะขึ้น FAIL และระบบจะไม่เริ่ม

4.4 Certificate และ Firewall

Cert สำหรับ HTTPS (Git for Windows มี openssl อยู่ใน Git Bash):

openssl req -x509 -newkey rsa:2048 -nodes -days 730 -keyout certs/server.key -out certs/server.crt \
  -subj "/CN=flora-gateway" -addext "subjectAltName=IP:<IP เครื่อง Windows>,IP:127.0.0.1"

เปิด Windows Firewall ให้เครื่องมือแพทย์และ Leaf ต่อเข้ามาได้ (PowerShell แบบ Administrator):

New-NetFirewallRule -DisplayName "Flora Gateway" -Direction Inbound -Protocol TCP `
  -LocalPort 443,7400,7410,7421,7422,7423,9500,2051 -Action Allow -Profile Domain,Private

4.5 Build และเริ่มระบบ

ใน PowerShell ที่โฟลเดอร์ flora-gateway (ครั้งแรกใส่ -Build):

.\windows\start-gateway.ps1 -Build

สคริปต์ทำตามลำดับ:

  1. รอ Docker Desktop พร้อม
  2. ตรวจพอร์ต COM จริง (check-com-ports.ps1) — ไม่ผ่านจะหยุด
  3. docker compose -f compose.windows.yaml up -d --build (port-guard ตรวจชื่อ COMn อีกชั้น)
  4. build serial-controller.exe (ครั้งแรกใช้เวลา 5–15 นาที)
  5. รัน serial-controller และ เริ่มใหม่เองถ้าหยุด (watchdog) log อยู่ใน logs\
เปลี่ยนค่าพอร์ตหลังติดตั้งเมื่อเพิ่มหรือแก้ device หน้า admin จะเขียนค่าสายของ pod ให้ตาม Device type แต่บน Windows ต้อง restart serial-controller เอง: ปิดโปรเซส serial-controller.exe ใน Task Manager แล้ว watchdog จะเริ่มใหม่ด้วยค่าใหม่ใน 5 วินาที

4.6 เริ่มเองเมื่อ login

.\windows\install-autostart.ps1            # ลงทะเบียน Task Scheduler "Flora Gateway"
.\windows\install-autostart.ps1 -Remove    # ถอนการตั้งค่า
  • Docker Desktop บน Windows ทำงานใน session ของผู้ใช้ ระบบจึงเริ่มเมื่อผู้ใช้ login
  • ถ้าต้องการให้เริ่มเองโดยไม่มีคนอยู่หน้าเครื่อง: เปิด Windows automatic sign-in (Sysinternals Autologon) และตั้งล็อกหน้าจออัตโนมัติ
  • ตั้ง Windows Update ไม่ให้รีสตาร์ตเองในเวลาทำงาน (Active hours)

6 เชื่อม Canopy, ไลเซนส์ และ Leaf

6.1 Canopy / Haber

  • ค่าเริ่มต้นมาจาก HABER_URL ใน .env หรือแก้ที่หน้า admin → Canopy link (ค่าที่หน้า admin ใช้แทน .env)
  • Canopy แบบ HTTPS ที่ใช้ cert ออกเอง: ติดตั้ง cert ของ Canopy ลง certs/canopy-trust.pem + certs/trust.env หรือใช้ http://<canopy>:7204

6.2 ไลเซนส์ (Flora Root)

  1. เปิด Root (https://172.22.19.81:8443) → Tenants → Edit license
  2. เพิ่มประเภทเครื่องที่ใช้ ถ้าไม่มีในรายการ ให้เลือก + custom code… แล้วพิมพ์ code เช่น draeger-medibus
  3. ตรวจ Max leaves / gateways / devices ให้พอกับที่ใช้จริง แล้วกด Issue new bundle
  4. ภายใน ~1 นาที gateway จะได้ไลเซนส์ใหม่ (หน้า admin → License)

6.3 เพิ่มเครื่องมือแพทย์

  • หน้า Devices → Add device → เลือก Device type และ Connection pod
  • ค่าสาย/framing ของ pod ถูกตั้งตาม Device type ให้อัตโนมัติ (มีกล่องแสดงล่วงหน้าก่อนกด Save)
  • 1 พอร์ต serial = 1 เครื่อง

6.4 Leaf

  • Leaf ต้องตั้ง FLORA_LEAF_ID และ gateway ต้องมี route ของ Leaf นั้นใน kong/kong.yaml
  • ใน Leaf → Set up bedside gateway → data-api base http://<gateway>:7410/data-api (หรือ HTTPS https://<gateway>/data-api)
