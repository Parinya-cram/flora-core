Payloads

From Canopy

Device types are normally managed at Canopy (Haber) and arrive with the approved parser images from the repository. Canopy receives them from Flora Root releases, and a hospital may add its own at Canopy; each row shows which. Here you can only set manufacturer, model, description and connection defaults.

Local templates

For a device Canopy does not list yet (gateway admin only). A template must use a parser image Canopy delivered and a parser inside it, and its type must be in the Root license. If Canopy later sends a type with the same code, the Canopy version replaces it.
