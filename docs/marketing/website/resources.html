Frequently asked questions

คำถามที่พบบ่อยCommon questions

ถ้าเครือข่ายล่มยังบันทึกได้หรือไม่?Can charting continue during a network outage?

Leaf มีฐานข้อมูลข้างเตียงของตัวเองและซิงก์กลับเมื่อการเชื่อมต่อพร้อมLeaf has its own bedside database and syncs when connectivity returns.

รองรับเครื่องมือแพทย์ทุกรุ่นหรือไม่?Does FLORA support every medical device?

ไม่ควรถือว่ารองรับทุกรุ่น ต้องตรวจรุ่น firmware protocol และทดสอบกับเครื่องจริงก่อนNo universal support is implied. Model, firmware and protocol must be checked on the real device.

ข้อมูลผู้ป่วยต้องขึ้นคลาวด์หรือไม่?Must patient data go to the cloud?

ข้อมูลหลักสามารถอยู่ภายในโรงพยาบาลได้ ส่วน Root ใช้สำหรับไลเซนส์และการจัดการอัปเดตCore records can remain in the hospital; Root supports licensing and update management.

เชื่อมกับ HIS อย่างไร?How does HIS integration work?

มีแนวทาง HL7 v2 และ API แต่ขอบเขตจริงขึ้นกับระบบและข้อกำหนดของแต่ละโรงพยาบาลHL7 v2 and API paths are available; actual scope depends on each hospital system and requirements.
