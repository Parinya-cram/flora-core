ความต่อเนื่องContinuity

ทำงานต่อได้เมื่อระบบล่มKeeps working through outages

  • Leaf มีฐานข้อมูลของตัวเอง บันทึกเคสต่อได้แม้เครือข่ายหรือ Canopy ล่มLeaf has its own database and keeps charting when the network or Canopy is down
  • ซิงก์แบบส่งซ้ำได้โดยไม่ซ้ำซ้อน (idempotent) เมื่อกลับมาเชื่อมต่อIdempotent sync when the connection returns, with no duplicates
  • พิมพ์ด้วยเสียงประมวลผลในเครื่อง ไม่ต้องใช้อินเทอร์เน็ตVoice dictation runs locally without the internet
การเข้าถึงAccess

สิทธิ์และการตรวจสอบย้อนหลังPermissions and audit

  • สิทธิ์ตามบทบาท (RBAC) เช่น วิสัญญีแพทย์ พยาบาล ผู้ดูแลระบบ และผู้ดูแลฟอร์มRole-based access for anesthesiologists, nurses, administrators and form authors
  • บันทึก audit ทุกการแก้ไขข้อมูลทางคลินิกและการส่งออกข้อมูลAudit trail for every clinical edit and data export
  • ปิดบังข้อมูลส่วนบุคคล (รวมชื่อภาษาไทย) ใน API และ AI StudioPersonal-data masking, including Thai names, in the API and AI Studio
  • ออกแบบเพื่อช่วยโรงพยาบาลปฏิบัติตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA)Built to help hospitals meet Thailand's PDPA obligations

ไลเซนส์และรุ่นซอฟต์แวร์ลงลายเซ็นดิจิทัลแบบ Ed25519 เครื่องจะไม่ติดตั้งไฟล์ที่ลายเซ็นไม่ถูกต้องLicences and releases are signed with Ed25519. Machines refuse any file whose signature does not verify.
